Papa Stud.io

Screenshot failure reviewer for Android testing tools. Scans your Gradle project and lets you review failures side-by-side.

Demo

Features

  • Supports Paparazzi, Roborazzi, and Compose Screenshot Testing
  • Delta, toggle, and slider comparison modes with zoom and pan
  • Accept baseline — copy the rendered image over the golden with one click, or bulk accept a whole scan
  • Scans multi-module Gradle projects
  • Video export of failures

Install

brew tap eboudrant/tap
brew install --cask papastud
